# Site core

`@a2aviary/site-core` owns the website domain formerly hosted in the legacy AWS
email package: pinned policy loading, canonical JSON/SHA-256, types, validators,
contract generation/examples, library metadata/selection and the confined behavior
loader. Email workers do not import this package. Policy JSON remains in `plans/`;
immutable generated contracts remain in `contracts/site/` and authored package
bytes remain in `library/`.

Install from the repository root with Node.js **22.23.3**:

```sh
npm ci
npm run build
npm run check
npm run site:check
npm test -w @a2aviary/site-core
npm run library:check
npm run test:parity
```

`npm run site:generate` is the relocated equivalent of services' earlier script.
It preserves immutable snapshots and exact generated bytes. `site:check` checks
without writing. The generator compiler writes inert catalog metadata here to
`src/library-data.ts` and presentation AST/CSS to generator's `src/library-data.ts`;
`library:check:static` and `library:check` reject stale outputs.

## Public API

The package exports named symbols from one explicit root entry; implementation
module paths are private. The runtime uses Node 22's native TypeScript stripping
on workspace source, with declarations emitted to `dist/` for downstream builds.
This retains policy paths at repository depth and makes authoring checks read the
current source/catalog rather than a stale bundled copy.

| Group | Named API |
| --- | --- |
| Policy and digests | `defaultPolicy`, `policyForVersion`, `assertPolicy`, `canonicalJson`, `sha256`, `specDigest`, `Policy` |
| Validation | `validateSiteSpec`, `validateAssets`, site and validation types |
| Contracts | `artifactDirectory`, `assertPolicySnapshot`, `flattenRules`, `generateContracts`, `makeExamples`, `Schema` |
| Library | `catalog`, `gzipBytes`, `behaviorBundle`, `selectedPackages`, `fontPackages`, `validateLibrarySelection`, `contentErrors`, `behaviorLoader`, `LibraryPackage`, `LibraryCatalog`, `LibraryContext` |

Two explicitly test-only subpaths export fictional fixtures:
`@a2aviary/site-core/fixtures/catalog` (`fixtureSubmission`, `writeSource`) and
`@a2aviary/site-core/fixtures/presentation` (`composition`, `compositionNames`,
`shells`). Runtime code must not import them. The presentation image and provenance
remain in [fixtures/presentation](fixtures/presentation/README.md). Neither API
provides a starter or customer template.

The generator retains compatibility re-exports for existing callers; platform
site-domain imports use site-core directly. See [verification and workspace
choices](../../docs/evidence/site-core-workspaces/README.md). Apache 2.0 applies;
dependency and original font licenses remain intact.
