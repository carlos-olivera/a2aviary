# 011 — Retired site adoption

Date: 2026-10-07
Status: Superseded by [012](012-catalog-site-administration-and-billing.md).

The former adoption decision and its complete implementation are preserved at the annotated [archive/imported-static](https://github.com/carlos-olivera/a2aviary/tree/archive/imported-static) tag. Adoption has been removed from the active platform. There are no registered client sites; the first site will be created new through the catalog workflow.

Only the generic administrator, billing eligibility, operation, cost and pilot records are retained by decision 012. A future separately scoped local CLI may prepare artifacts; the core alone validates and deploys. No replacement CLI is designed or implemented here.
